# oid2name

Ferramenta de baixo nível que se conecta e examina os catálogos do sistema e o diretório de dados para ajudar os administradores a traduzirem os OIDs (Object Identifiers) internos em nomes reais de arquivos ou objetos.

## Exemplo

```bash
oid2name -d meubanco -x
```
