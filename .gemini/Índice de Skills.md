# 🧠 Painel Central de Skills (IA)

Este índice organiza todas as capacidades avançadas integradas a este vault. Cada skill fornece à IA o contexto necessário para manipular formatos específicos e realizar tarefas complexas.

## 📋 Catálogo de Habilidades

| Skill | Tipo | Objetivo Principal |
| :--- | :--- | :--- |
| [[gemini/skills/obsidian-markdown/SKILL_obsidian-markdown\|Markdown Avançado]] | Edição | Manipular wikilinks, callouts, propriedades e blocos. |
| [[gemini/skills/json-canvas/SKILL_json-canvas\|JSON Canvas]] | Visual | Criar e editar fluxogramas e mapas mentais `.canvas`. |
| [[gemini/skills/obsidian-bases/SKILL_obsidian-bases\|Obsidian Bases]] | Dados | Gerenciar tabelas dinâmicas e fórmulas em arquivos `.base`. |
| [[gemini/skills/obsidian-cli/SKILL_obsidian-cli\|Obsidian CLI]] | Sistema | Interagir com a interface do app e ferramentas de dev. |
| [[gemini/skills/defuddle/SKILL_defuddle\|Defuddle]] | Web | Extrair conteúdo limpo de URLs para economia de tokens. |

## ⚠️ Requisitos de Sistema

> [!warning] Dependências Externas
> As habilidades de **Sistema** e **Web** requerem que o Node.js e as respectivas CLIs estejam instalados no seu computador e acessíveis no PATH.

> [!tip] Uso Sugerido
> Ao pedir para criar um fluxo de trabalho, mencione se prefere uma nota comum (`.md`) ou uma visualização em tela (`.canvas`).
